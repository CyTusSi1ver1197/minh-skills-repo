# skill-factory

Two Agent Skills, `running-when-a-request-is-made` and `information-gathering-for-plan`, with the benchmark used to build and test them.

- `bench/skill-token/`: benchmark harness, fixture repo and results. Skill snapshots are in `bench/skill-token/versions/` (v1, v2.0, v2.1, v2.2).
- `BuildPlans/`: the plans used to build each version.
